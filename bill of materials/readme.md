## bill of materials
<br />

|volgnummer|naam|omschrijving|nieuw/recup|kostprijs/stuk|aantal|subtotaal|
|----------|----|------------|-----------|---------|------|---------|
|         1|  Raspberry Pi Pico W  | Krachtige microcontroller die de sensoren uitleest, de PID-regeling uitvoert en de motoren aanstuurt. Dankzij de hoge kloksnelheid kan de regeling snel en nauwkeurig worden uitgevoerd.           |           |              |      |         |
|         2|  2S LiPo Batterij (7.4V) + lader |  Voedingsbron van de robot. Levert de elektrische energie voor de motoren en elektronica. De batterij kan na gebruik opnieuw worden opgeladen met de bijhorende lader.          |           |              |      |         |
|         3|  Micro metal DC motor 50:1 | Kleine gelijkstroommotor met een ingebouwde tandwielkast. De 50:1 vertraging zorgt voor meer koppel en maakt een gecontroleerde aandrijving van de wielen mogelijk.           |           |              |      |         |
|         4|  H-brug (DRV8835)  |  Motorstuurmodule waarmee de draairichting en snelheid van de DC-motoren geregeld kunnen worden. De snelheid wordt geregeld door middel van een PWM-signaal vanuit de microcontroller.          |           |              |      |         |
|         5|  Array sensor (QTR-8A)  | Sensorarray met meerdere infraroodsensoren die het contrast tussen de witte ondergrond en de zwarte lijn detecteren. De microcontroller gebruikt deze metingen om de positie van de lijn te bepalen.           |           |              |      |         |
|         6|  Bouten | Mechanische bevestigingsmiddelen waarmee onderdelen zoals motorbeugels, de printplaat en andere constructiedelen stevig aan het chassis worden gemonteerd.           |           |              |      |         |
|         7|  Polulu wiel (40 x  7) zwart  |  Aandrijfwiel dat rechtstreeks op de motoras wordt bevestigd. Het zorgt voor de voortbeweging van de robot en biedt grip op het parcours.          |           |              |      |         |
|         8|  Polulu earmotor bracket  | Metalen bevestigingsbeugel waarmee de gearmotor stevig aan het chassis van de robot wordt bevestigd.           |           |              |      |         |
|         9|  Tuimelschakelaar  |  Schakelaar waarmee de voedingsspanning van de robot in- en uitgeschakeld kan worden. Dit dient als de hoofdschakelaar van de robot.          |           |              |      |         |
|         10|  Dupont draadjes  | Flexibele verbindingsdraden voor het aansluiten van elektronische componenten tijdens de ontwikkelings- en testfase. Voor het uiteindelijke product mogen deze volgens de specificaties niet aanwezig zijn.           |           |              |      |         |
|         11|  Drukknop  | Bedieningsknop waarmee de robot kan worden geactiveerd.          |           |              |      |         |
|         12|  Led  | Visuele indicator die de gebruiker informeert over de status van de voeding.           |           |              |      |         |
